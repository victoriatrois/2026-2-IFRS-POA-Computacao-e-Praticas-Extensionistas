## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Backend authentication

The login screen at `/login` uses the backend `POST /auth/login` endpoint. Set
`NEXT_PUBLIC_API_URL` to the backend origin when it is not available at
`http://localhost:8080`. Access and rotating refresh tokens are kept for the
current browser session; protected API requests send the access token and
automatically renew it after an expired-token response. Signing out revokes the
refresh token through `POST /auth/logout`.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
